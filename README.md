# Inventory Hub - Frontend

Frontend for my inventory management app. Users can register, log in, manage their own items, and browse other users' inventory.

Built with React, Vite, JavaScript, and CSS.

## Live Site

https://inventory-hub-frontend-chi.vercel.app

## Setup

```bash
git clone https://github.com/calebmcintyre8501/inventory-hub-frontend.git
cd inventory-hub-frontend
npm ci
npm run dev
```

The frontend runs at http://localhost:5173.

The backend needs to be running on port 3000 for local development.
